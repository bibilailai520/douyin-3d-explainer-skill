# 最近几期的制作修正 · 1.2.0

本版依据 Markdown 写作 V9、客服知识库 V4、AI 蒸馏章节修订 V2、Codex 十句提示词工程整理。以下区分账号共用起点与单期题材配方；新片仍按本期稿件和配音安排动作。

## 开场和板面

开头第一帧即开始由近到远，`power2.out(t/4.15)`在约4.15秒归位；两块等大板预先同平面排好，再由父级相机共同退远。下一板实体可预露，标题和内容按各自镜头的全局`start`显现，防止解释提前泄露。开头检查0、1/30、0.3、1.5、3.9、4.15秒。

背景采用低对比浅色动态网格；柔白厚板、深色主字、章节低饱和换色。主体对象统一左上主光、可见侧壁、紧贴物体的接触阴影和右下软投影。阴影跟随物体高度、接触和反弹变化。

## 动作要解释对象

- 小卡从高处下落，首次接触短压缩再回弹；音符与首次接触同帧，板内对象稳定后停住。
- 箭头表达关系，实际传递优先用文件、纸页或主题物件。删除没有信息推进的循环小圆点。模板网络演示改为文件完成两次传递后停住。
- 环和圆盘共用同一个布局中心、`border-box`与变换原点；不同`translateZ`会制造透视错心，需看倾斜后的实际帧。
- 真实翻书固定书脊，右页抬起、经过上方弧线、弯曲并落到左页；封面保持摊平。翻封面与翻纸页分别建模。
- 按配音词锚分阶段出现证据、比较、答案或结果。讲“盖住答案”后，答案图形要彻底隐藏；不要在预露板或早期状态提前显示。

## 章节、字幕和手机阅读

右上角独立`ChapterProgress`组件只展示当前章名及章序，上方文字、下方分段线。标题46px、章序48px、宽540px、right=72px、top=24px是当前起点；分段线与字形保留空隙。段数来自`chapters.length`，已完成满格、未来为空、当前按时间推进，末帧保留完整状态。

模板使用独立类名，避免旧`.chapter-nav`规则覆盖。重点条件、数量、否定词与对象标签在390px缩图仍可读；近期修正中30px浅色条件字调整到48px，正文多在40–48px。按实际排版调整，优先删冗余句和腾出空间。

字幕保持60px、bottom=28px，近期版本采用70%不透明灰底、白字与明亮重点词；语义配色仍可按本期角色配置。屏幕空间字幕与章节不随板面倾斜。

## 音效与原声

知识库 V4从密集事件改为关键事件，单期21个是案例记录，不是各期配额。最近两期也采用稀疏音效。保留落地、翻页、跳跃及关键状态变化，不给每个细小运动铺声。

用户反馈音量小，检查SFX solo和完整混音，再调增益或频段；记录配音遮蔽的事件。只改画面用`reuse_audio.py`保留AAC包与时间戳；改音效则重新混音和测编码音轨。

## 封面与版本

最近 Markdown 一期明确弃用旧拼贴模板，仍为1080×1440。用新主题排版、清楚的大标题和与主题物件互动的机器人；IP保持原身份与接触关系。旧模板作为用户要求复刻时的可选资源。

交付新版本，保留旧工程。最终检查绑定实际MP4哈希；修改后只复用仍适用的旧证据。独立报告若中断、针对旧版或待核，保持原状态，另写最终修复核对。人工连续观看、听检和独立评审逐项记录。

## 本版可运行资源

- 模板已经实现：立即拉远、浅色动态网格、板内厚度和阴影、按全局起点显示内容、动态章节进度、灰底字幕、文件传递、可断点分段渲染。
- [ObjectWorld3D.tsx](../assets/recipes/ObjectWorld3D.tsx)与[object-world.css](../assets/recipes/object-world.css)：来自近期工程的真正三维物件配方，含书页弯曲、文档、齿轮、文件夹和数据流。按需复制到新工程`src/`，导入CSS，在`Scenes.tsx`路由到`<ObjectWorld3D shot={shot} l={l}/>`。现有依赖含Three.js；`shot.type`、`beats`和`worldLabels`需要按本期重写。
- 配方含特定台词、模式和时间；新主题自行画语义对象，保留动作与渲染机制。
- `npm run typecheck`、`check:layout`、`check:presentation`、`check:render-plan`用于类型、几何、章节/开场和帧覆盖验证；实际编码帧及声音另行检查。

# 视觉与手机阅读规范

以下为账号当前起点，用户本期明确要求覆盖默认值。母版1920×1080、30fps。390px宽缩图是阅读复核依据；新主题按实际对象、字数和发布界面调整。

## 功能配色

|角色|色值|使用方式|
|---|---|---|
|背景|`#F8FAFD`叠章节底色|低对比浅色动态网格，按帧确定位置，章节低饱和微变|
|卡片|`#FBFCFE`|柔白大板、小卡和短标签|
|文字结构|`#243B53`|标题、正文、字幕底|
|暖色功能|`#DB9A39`|缓存案例中表示重算、费用和计算消耗|
|冷色功能|`#24A995`|缓存案例中表示命中、复用与节省|
|公共信息|`#4F90CE`|输入、输出、公共模块、选中导航|

浅底上的短字用深色：蓝`#326B9A`、绿`#146F65`、金`#8C5D20`。字幕重点字用浅色：蓝`#D5EDFF`、绿`#BDFFE9`、金`#FFE7BB`。这些是对比度变体，不另赋含义。

新主题在`episode.json.highlightRoles`中定义角色。许可与风险可分别映射薄荷和琥珀，无需每个主题都讲成本。词色结合句子，例如“不用重算”归到节省。每条caption可提供`emphasis`词色覆盖；场景用相同角色。

保持背景柔和、文字深、重点鲜明。60%基底/25%结构/15%强调是可选视觉权重，不按每帧像素强制分配。避免额外高饱和红色和每块不同的强调色。

## 大板、同平面和轨道

`src/rail-geometry.ts`集中控制母版坐标：

- BOARD：x400、y166，局部1190×670；共享READING_SCALE=1.12。
- 所有卡片局部scale=1；同一个投影矩阵、同一个远心圆轨道，半径6000，角间隔0.248。
- 稳定阅读时板面投影约x317..1678、y158..854，给上方章节与下方字幕留空。
- IP前景canvas起点x55/y300，390×500。左移为放大后的文字让位；按实际头部、手势和气泡范围调整。
- 主板32层厚边、约51px深、圆角34px；侧壁用低饱和边色与深海蓝混合。左上主光，右下软投影，保留接触阴影。
- 透视8000、倾角X28°/Y−3°；开头约1.48倍近景共同退远，到约4.15秒归位。

两张板先排好，再共同变化相机。从第0帧开始退远，首秒持续变化，约4.15秒归位。左侧预露是实际下一张板；标题与正文到该镜全局start才显示，板实体始终在场。转场时沿同一圆弧向右到阅读位，旧板退出右边界。不要给左卡单独缩放、单独推远或延迟创建。修改板宽、公共缩放、角间隔或IP位置后，重新解交叉时刻，运行`npm run check:layout`并查看实际帧。

## 字号和字幕

模板标题68px、主要小卡文字约47px，流程对象短标签约40px，再随板面1.12倍投影。缓存案例中，原31px标签改到40px后实际约45px。新主题按字数和槽位调字号；避免为了塞说明而把核心信息缩成小字。

字幕60px，近期灰底`rgba(65,67,80,.70)`、白字、圆角18px、内边距9px/23px，阴影8px/12px/22px。bottom=28px。字幕是屏幕空间，不跟随卡片缩放；尽量一行约22字。关键词保持明亮角色色；按本期要求可切回深海蓝底。平台覆盖随发布方式变化，用带UI预览确认。

右上角`ChapterProgress`独立组件展示当前章名46px、章序48px；文字在上、分段进度线在下。top=24px、right=72px、宽540px。段数从章节数组生成；完成段满格、未来段为空。长章名优先缩短措辞或加宽区域，不缩成难读小字。左上放账号Logo。旧多章导航仅保留历史样式，不再挂载。

## 小卡、图解和语义

小卡从板面上方落到明确槽位，影子由宽淡模糊变得紧实；首次接触短压缩/回弹，同时响音符。后出现的对象在更高层，但不遮住必须读的标签。稳定后停止无意义漂移。

箭头和运动对象共享曲线。浅底路径采用足够深的颜色和线宽，参考三维管线半径0.047、透明度0.88；2D路径约5.5px。这些数值按新镜头的缩图辨识度调整。

原理图以对象变化、路线、状态和消耗为主，长句留给口播。下方总结条与对象标签分层排，字号增大后重新检查间距。已有代码见[semantic-recipes.md](semantic-recipes.md)。

放大检查覆盖：开头裁字、预露板出现、IP/气泡挡字、落地卡撞标题、底条盖说明、字幕碰边、转场是否同平面。不要只看一张稳定帧。

不印“作者原文配图”“画面预演·配音待对齐”“示意”等生产标签，不把检查用红框带进正式片。

# 视觉规范

以下是当前账号默认值，用户本期明确修改时以新要求为准。

## 坐标与安全区

母版1920×1080。章导航约x120..1640、y35..121；主大板约x430、y180、w1190、h670；IP前景canvas约x135、y300、w390、h500。右侧约260px避免放关键人物和文案；底部100px尽量保留。真实抖音播放器的头像、按钮和字幕随设备/展示方式不同，以上是设计保护区，不保证所有机型绝对无遮挡；发布前用带平台UI的预览核对。

字幕默认52px，最多约22个汉字一行，可两行但避开板中关键操作。灰底rgba(65,67,80,.70)，不是“70%透明”。白字、黄色重点词，圆角24px、12px/18px/29px级别软影。主标题建议64–72px，板中核心标签40–48px；辅助字过小时优先减少字，不靠缩到20px塞满。390px宽缩图复核实际可读性。

## 大板立体感

采用真实preserve-3d层叠厚边：32层，约51px深，圆角34px；按章节主色从亮到暗渐变，右侧和底部形成可见侧壁。面板translateZ(2px)，细边、纸面微点纹；主板perspective约2000px，rotateX约28°、rotateY约−3°。板外再放右下大软投影，不用一条蓝色底边代替厚度。

开场scale约1.48并额外倾斜，然后3.8秒左右退到正常；要看得出相机变化，标题不能因此裁断或快速晃动。用卡片与机器人不同景深建立层次。阴影方向保持左上主光→右下投影，不要每个元素各自投向不同方向。

## 小卡片落地

1. 起点在板面上方、沿局部Z/高度下降；不要从底部上升或只淡入。
2. 影子留在目标地面：高处时宽/淡/糊；接近时变小/浓/清晰。
3. 接触瞬间短暂压缩/回弹，物体归位后停止漂移；音符在第一次接触时触发，误差≤1帧目标。
4. 外圈多层厚边和右下阴影保留。目标位置按信息层级排列；先出现卡在较低zIndex，后出现卡更靠前，但绝不遮住必须读的标签。

## 转场与图解

主卡从左向右滑入，IP跳起跨过边沿。内部对象可以沿同一贝塞尔曲线传递，路线先画出或随对象显现；到达后停在明确槽位，不能在22秒一类交换场景里重新随机选路。连续镜头尽量用同一物件承接，而非所有元素消失再全部出现。

颜色随章节由淡珊瑚、薄荷青、浅紫、暖沙黄、浅绿柔和过渡，约2.4秒。板中小卡再按对象类别使用蓝/青/橙/紫等搭配，不让所有元素全片单一蓝。不要用颜色独自承担“允许/拒绝”，同时有符号和文字。

不要把“作者原文配图”“画面预演·配音待对齐”“实测”“示意”等生产标签无脑印到用户成片上。概念图可在制作说明交代；必须披露的事实边界用有意义的解释，而不是到处盖水印。

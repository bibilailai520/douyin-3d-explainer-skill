# 配音、字幕与音效

## 原音频保护

用户提供成品配音时，先保留其原件/哈希，不另合成音色。只有用户授权才做词语剪接修正，修正前后保留听检片段和剪接点。响度处理不等于变速；不得为了卡时长任意加速。转写外发/云端处理需用户授权，本包默认本地。

## 本地字级对齐

```powershell
python -m pip install -r "<技能根>/requirements-asr.txt"
python "<技能根>/scripts/align_voice.py" --project . --model "本地faster-whisper模型目录"
```

脚本输出`qa/asr.json`原始识别和`qa/alignment.json`对照报告、`qa/captions-proposed.json`建议字幕。它不会直接覆盖episode.json。把配音稿的句子与实际识别核对后再写入captions，修正英文词（MCP、BOT）、数字、否定词等容易误判处。配音与稿子不一致时以实际发声生成字幕，或经用户授权修音频；不能用正确字幕掩盖相反口播。

字级时间来自ASR词时间再按词内字符映射，词内划分仍是估计；未识别字只能在有锚点的窗口内估计。记录估计范围和匹配率。不能把强制对齐产物宣称为逐字人工听检。没有ASR条件时允许听检手动对齐，但标明来源。

每条字幕建议≤22字，句意完整，不在“只/不/不是”等否定词之后突然跨屏。字幕开始贴合发声，末尾留小余量但不盖下一条；字幕、镜头和落地音的时间通过同一fps取整。输出SRT与烧录文字一致。

## 事件表

`episode.json.sfx`：`at`全片秒、`kind`为note/hop/land/whoosh/charge、`frequency`可选、`db`单次峰值目标、`anchor`说明语义。卡片item的`dropAt`是镜头局部秒，首次接触时`shot.start+dropAt+0.72`（以实际落体函数为准）对应音符；不是卡片刚出现就先响。

Do/Re/Mi/Fa/Sol/La/Si频率约523.25/587.33/659.25/698.46/783.99/880/987.77Hz。六张卡用前六音，七张用七音；不要为了奏完音阶硬插第七次敲击。音符约0.19秒、短渐入/渐出，避免咔声；whoosh约0.24秒；跳起和落地分别短促、质地不同。第0秒留人声，不放开屏爆音。

## 混音

`mix_audio.py`用FFmpeg把原声调到稳定的可懂响度，代码合成音效，再两遍测量/调平完整混音。默认输出48kHz双声道PCM及完整混音约−14 LUFS、TP≤−1.2dBTP；这是起点而不是抖音统一标准。手机听检优先：人声清楚、短音效可辨、不刺耳。`--sfx-gain-db 3`可加大音效，但增大后必须重新测真峰值、检查叠加和人声遮蔽。

记录原音频哈希、语速未变、配音处理链、音效数量与测量；以最终编码AAC再测一次。只看WAV没有削波，不能代表编码后真峰值也安全。不能拿音频相关系数代替主观响度验收。
